# Helpdesk Troubleshooting Knowledge Base

Step-by-step fixes for the most common IT support issues, written the way I document them in a ticketing system: **Symptoms → Likely causes → Steps → Verify → Prevent / Escalate**.

Built by **Adams Samson**, Remote IT Support & Cloud Identity Engineer (Microsoft 365, Entra ID, Active Directory, ServiceNow).

## How I troubleshoot

`Identify → Diagnose → Resolve → Document → Prevent recurrence`

1. **Identify:** What exactly is the user seeing? Since when? What changed?
2. **Diagnose:** Start with the simplest, most likely cause. Change one thing at a time.
3. **Resolve:** Apply the fix and confirm it with the user.
4. **Document:** Record the cause, the fix and the time taken in the ticket.
5. **Prevent:** Fix the root cause or update the process so it doesn't repeat.
